# Codyssey Quiz Game

Python 기초 지식을 퀴즈 형식으로 학습할 수 있는 콘솔 기반 퀴즈 게임입니다.

사용자는 기본으로 제공되는 퀴즈를 풀거나 직접 새로운 퀴즈를 등록할 수 있으며, 게임 결과와 최고 점수는 JSON 파일에 저장하여 다음 실행에도 유지할 수 있습니다.

## 1. 프로젝트 개요

- **프로젝트명:** Codyssey Quiz Game
- **개발 언어:** Python
- **실행 환경:** Windows 및 Unix 계열 운영체제의 터미널
- **프로그램 형태:** 콘솔 기반 퀴즈 게임
- **주요 학습 내용:** Python 기초 문법, 클래스와 객체, 함수, 조건문, 반복문, 파일 입출력 및 예외 처리

이 프로젝트는 Python의 기본 문법과 객체지향 프로그래밍 개념을 활용하여 퀴즈 게임을 구현하는 것을 목적으로 합니다.

## 2. 퀴즈 주제 선정 이유

**주제: 파이썬 기초 학습**

Python은 프로그래밍을 처음 접하는 학습자가 비교적 쉽게 배울 수 있는 프로그래밍 언어입니다.

프로젝트의 주제를 Python 기초 학습으로 선정한 이유는 다음과 같습니다.

- **기초 문법 복습:** 변수, 자료형, 조건문, 반복문, 함수 등 Python의 핵심 문법을 반복적으로 학습할 수 있습니다.
- **학습 내용의 이해도 확인:** 객관식 퀴즈를 통해 각 문법의 사용 방법과 실행 결과를 확인할 수 있습니다.
- **실습 중심의 학습:** 단순히 문법을 읽는 것에서 끝나지 않고, 코드를 직접 확인하고 정답을 선택하는 방식으로 학습할 수 있습니다.
- **확장 가능성:** 사용자가 새로운 퀴즈를 직접 등록할 수 있어 학습 범위를 자유롭게 확장할 수 있습니다.

## 3. 실행 방법

### 3-1. 개발 환경

- Python 3
- 별도의 외부 라이브러리 설치 없이 실행 가능
- Python 표준 라이브러리 사용

### 3-2. 저장소 복제

터미널 또는 PowerShell에서 다음 명령어를 실행합니다.

```bash
git clone https://github.com/Soo-Young-Jung/codyssey_quiz_game.git
```

저장소 디렉터리로 이동합니다.

```bash
cd codyssey_quiz_game
```

### 3-3. 프로그램 실행

다음 명령어로 프로그램을 실행합니다.

```bash
python quiz_game.py
```

실행 후 메뉴에서 원하는 기능의 번호를 입력합니다.

### 3-4. 메뉴 구성

```text
=== Quiz Game ===
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록 보기
4. 점수 확인
5. 종료
```

## 4. 기능 목록

| 기능 | 설명 |
|---|---|
| 퀴즈 풀기 | 등록된 퀴즈를 순서대로 출제하고 정답 여부를 확인합니다. |
| 퀴즈 추가 | 문제, 4개의 선택지, 정답 번호, 힌트를 입력하여 새로운 퀴즈를 등록합니다. |
| 퀴즈 목록 보기 | 현재 등록되어 있는 퀴즈의 문제 목록을 확인합니다. |
| 점수 확인 | 현재 점수, 최고 점수 및 이전 게임 기록을 확인합니다. |
| 힌트 확인 | 퀴즈 진행 중 힌트를 확인할 수 있으며, 사용 시 5점이 차감됩니다. |
| 메뉴 돌아가기 | 퀴즈 진행 중 6번을 입력하여 메뉴로 돌아갈 수 있습니다. |
| 데이터 저장 및 불러오기 | 퀴즈 데이터, 최고 점수, 점수 기록을 JSON 파일로 저장하고 불러옵니다. |
| 입력값 검증 | 숫자가 아닌 입력, 빈 입력, 허용 범위를 벗어난 입력을 처리합니다. |
| 예외 처리 | 데이터 파일이 없거나 손상된 경우 기본 퀴즈 데이터를 사용하며, 키보드 인터럽트와 입력 종료를 처리합니다. |

### 점수 산정 방식

- 정답을 맞히면 **20점**을 획득합니다.
- 힌트를 사용하면 **5점**이 차감됩니다.
- 최종 점수가 0점 미만이면 0점으로 처리합니다.
- 게임 종료 시 최고 점수와 비교하여 기록을 갱신합니다.

## 5. 파일 구조

```text
codyssey_quiz_game/
│
├── quiz_game.py   # 메인 프로그램 및 퀴즈 게임 기능
├── state.json     # 게임 데이터 저장 파일 (실행 시 자동 생성)
├── README.md      # 프로젝트 설명 문서
└── .gitignore     # Git 추적 제외 파일 설정
```

### 주요 파일 설명

| 파일명 | 설명 |
|---|---|
| `quiz_game.py` | Quiz 및 QuizGame 클래스를 정의하고 게임 실행, 퀴즈 관리, 점수 관리, 데이터 입출력 기능을 구현합니다. |
| `state.json` | 사용자가 추가한 퀴즈, 최고 점수, 게임 기록을 저장합니다. |
| `README.md` | 프로젝트의 개요와 실행 방법, 주요 기능 및 파일 구조를 설명합니다. |
| `.gitignore` | Python 캐시 파일, 가상환경 및 게임 데이터 파일 등이 Git에 포함되지 않도록 설정합니다. |

### 클래스 구성

**Quiz 클래스**

개별 퀴즈 하나를 관리하는 클래스입니다.

- 속성: `question`, `choices`, `answer`, `hint`
- 메서드:
  - `show_question()`: 문제와 선택지를 출력합니다.
  - `check_answer()`: 사용자가 입력한 답이 정답인지 확인합니다.

**QuizGame 클래스**

퀴즈 게임 전체를 관리하는 클래스입니다.

- 주요 속성:
  - `quizzes`: 퀴즈 목록
  - `best_score`: 최고 점수
  - `score`: 현재 점수
  - `save_score_historys`: 게임 점수 기록 목록
- 주요 메서드:
  - `show_menu()`: 메인 메뉴를 출력합니다.
  - `play()`: 퀴즈를 진행하고 결과를 계산합니다.
  - `add_quiz()`: 새로운 퀴즈를 등록합니다.
  - `list_quizzes()`: 등록된 퀴즈 목록을 출력합니다.
  - `show_score()`: 점수 및 게임 기록을 출력합니다.
  - `save_data()`: 게임 데이터를 JSON 파일로 저장합니다.
  - `load_data()`: JSON 파일에서 게임 데이터를 불러옵니다.
  - `reset_quizzes()`: 기본 퀴즈 데이터를 초기화합니다.
  - `go_back_to_menu()`: 메인 메뉴로 돌아갑니다.

## 6. 데이터 파일 설명 (state.json)

`state.json`은 게임 진행 중 생성되는 데이터를 저장하는 JSON 파일입니다.

프로그램을 다시 실행해도 이전에 등록한 퀴즈와 최고 점수, 게임 기록을 유지할 수 있도록 사용합니다.

### 6-1. 저장 데이터 구성

| 키 | 자료형 | 설명 |
|---|---|---|
| `quizzes` | List | 등록된 퀴즈 목록 |
| `quizzes[].question` | String | 퀴즈 문제 |
| `quizzes[].choices` | List | 4개의 선택지 |
| `quizzes[].answer` | Integer | 정답 번호 (1~4) |
| `quizzes[].hint` | String | 퀴즈 힌트 |
| `best_score` | Integer | 최고 점수 |
| `save_score_historys` | List | 게임별 점수 기록 |
| `save_score_historys[].score` | Integer | 해당 게임의 최종 점수 |
| `save_score_historys[].date` | Integer | 게임 기록이 생성된 Unix timestamp |
| `save_score_historys[].correct_quiz_count` | Integer | 정답을 맞힌 문제 수 |
| `save_score_historys[].total_quiz_count` | Integer | 전체 문제 수 |

### 6-2. 데이터 저장 예시

```json
{
    "quizzes": [
        {
            "question": "파이썬에서 변수에 값을 저장하는 방법은?",
            "choices": [
                "number := 10;",
                "number = 10",
                "10 = number",
                "int number = 10"
            ],
            "answer": 2,
            "hint": "변수에 값을 대입할 때 사용하는 기호를 생각해 보세요."
        }
    ],
    "best_score": 100,
    "save_score_historys": [
        {
            "score": 100,
            "date": 1790000000,
            "correct_quiz_count": 5,
            "total_quiz_count": 5
        }
    ]
}
```

### 6-3. 데이터 파일 관리 방식

- **저장 위치:** 프로젝트 루트 디렉터리
- **인코딩:** UTF-8
- **파일 형식:** JSON
- **저장 방식:** Python의 `json.dump()` 사용
- **불러오기 방식:** Python의 `json.load()` 사용
- **한글 저장:** `ensure_ascii=False` 옵션을 사용하여 한글이 그대로 저장되도록 처리합니다.
- **파일이 없는 경우:** 기본 퀴즈 데이터를 불러옵니다.
- **파일이 손상된 경우:** JSON 파싱 오류를 처리하고 기본 퀴즈 데이터를 사용합니다.
- **Git 관리:** `.gitignore`에 `state.json`을 등록하여 개인별 게임 데이터가 저장소에 올라가지 않도록 설정합니다.

게임 데이터는 퀴즈 추가 또는 게임 종료 시 저장되며, 프로그램 종료 과정에서도 저장을 시도합니다.
